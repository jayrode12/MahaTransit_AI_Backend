MahaTransit-AI
MahaTransit AI is a centralized complaint management system for Mumbai's public transport network. It leverages AI for speech-to-text, multilingual translation, duplicate complaint detection, and priority prediction while providing role-based dashboards for citizens, officers, and administrators. MahaTransit AI is a centralized web application that enables citizens to report transport-related issues through text or voice while helping transport authorities efficiently manage and resolve complaints. The platform integrates Artificial Intelligence to improve complaint processing through Speech-to-Text, Multilingual Translation, Duplicate Complaint Detection, and Priority Prediction.

📌 Problem Statement

Public transport complaints are currently scattered across multiple platforms, making it difficult for commuters to report issues and for authorities to manage them efficiently.

MahaTransit AI provides a single platform where complaints are intelligently processed and forwarded to the appropriate transport authority, improving response time and reducing duplicate reports.

🎯 Objectives Centralize complaint management for Mumbai public transport. Simplify complaint submission using text and voice. Support multiple languages (English, Hindi, Marathi). Detect duplicate complaints automatically. Predict complaint priority using AI. Provide dedicated dashboards for transport authorities.
